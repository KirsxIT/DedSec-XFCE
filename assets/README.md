# Local wallpaper assets

The wallpaper media is intentionally not included in this public repository.
Only add files you have the right to use:

- `desktop-background.png` — static desktop wallpaper fallback
- `terminal-background.png` — XFCE Terminal background
- `dedsec-live-wallpaper.mp4` — optional animated desktop background

Place the files in this directory before running `../install.sh`. The installer
checks that all three files are present before making system changes.
