# Wallpaper assets

The `with-wallpaper-assets` branch includes these files. The `main` branch
omits the media; if using that branch, add files you have the right to use:

- `desktop-background.png` — static desktop wallpaper fallback
- `terminal-background.png` — XFCE Terminal background
- `dedsec-live-wallpaper.mp4` — optional animated desktop background

Place all three files in this directory before running `../install.sh`. The
installer checks that they are present before making system changes.
